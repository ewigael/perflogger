# perflogger

A performance tracking package for Python devs

## Quick start

##### Use pip

_Pypi package coming soon_

##### Build from sources

```bash
# Download sources
git clone https://github.com/ewigael/perflogger
# Move to sources directory
cd perflogger
# Install from sources with pip
pip install .
```
